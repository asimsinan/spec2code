## Why this is Documentation Substitution

Strongest example after the seed. A markdown file whose title 'Phase 4: Testing, Documentation & Deployment - COMPLETE ✅' asserts phase completion, followed by a 'Status: ✅ ALL TASKS COMPLETED' banner and a seven-row table of ✅ COMPLETE task entries. The Phase-Complete claim is supported by the file's own assertions.
